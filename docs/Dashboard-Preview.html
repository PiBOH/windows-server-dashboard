❓ Why the CPU temperature is missing ×

No source answered, so the dashboard has no number to show. It does not measure the temperature itself and it starts nothing: it reads what a program that does measure it publishes. Install one of these and leave it running - no add-on, no plug-in, nothing to install inside the dashboard:
Core Temp the lightest, one reading per core LibreHardwareMonitor successor of Open Hardware Monitor Open Hardware Monitor the older, still used HWiNFO wants its WMI provider switched on
Do not count on the BIOS or on ACPI: the BIOS almost never exposes the temperature of the CPU, and the ACPI thermal zone is a zone of the motherboard - often the chassis - not the processor. Those programs read the CPU itself, which is why they are the way that works.
If one of them already runs and the reading is still missing, look at the ServerDashboard log on the server: it names every source it tried and the ones it found. Core Temp running on the desktop is not always visible to a dashboard running as a service: switch on "enable global shared memory" in Core Temp > Options > Advanced, or enable logging in Core Temp, so the dashboard can read its log file.
